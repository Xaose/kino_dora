# Инструкция по добавлению фильмов в Firebase

## Способ 1: Через веб-интерфейс

1. Запустите приложение: `npm start`
2. Откройте в браузере: `http://localhost:3000`
3. В консоли браузера (F12) выполните:
   ```javascript
   window.location.hash = 'addmovies';
   ```
   Или добавьте в код навигацию на страницу `addmovies`
4. Нажмите кнопку "Добавить 5 фильмов"
5. Дождитесь завершения операции

## Способ 2: Через консоль браузера

1. Запустите приложение: `npm start`
2. Откройте консоль браузера (F12)
3. Выполните команду:
   ```javascript
   await addMoviesToFirebase()
   ```
4. Дождитесь завершения операции

## Добавляемые фильмы

Скрипт добавит следующие 5 фильмов:

1. **Интерстеллар** (2014) - Фантастика, Драма, Приключения
2. **Начало** (2010) - Фантастика, Триллер, Экшн
3. **Матрица** (1999) - Фантастика, Экшн
4. **Побег из Шоушенка** (1994) - Драма
5. **Форрест Гамп** (1994) - Драма, Комедия, Романтика

## Заполняемые поля

Каждый фильм содержит следующие поля:
- `name` (название)
- `description` (описание)
- `director` (режиссер)
- `genre` (массив жанров)
- `age` (возрастной рейтинг)
- `release_year` (год выпуска)
- `time` (длительность)
- `budget` (бюджет)
- `poster` (URL постера)
- `trailer` (URL трейлера)
- `movie` (URL видео)
- `actors` (массив актеров)

## Примечания

- Все фильмы используют YouTube ссылки для видео и трейлеров
- Постеры используют временные изображения с Unsplash
- После добавления фильмы будут доступны в коллекции `movies` в Firebase Firestore
- Проверьте консоль браузера для детальной информации о процессе добавления
