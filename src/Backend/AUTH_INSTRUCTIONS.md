# Инструкция по использованию аутентификации Firebase

## Настройка Firebase Authentication

### 1. Включите Email/Password аутентификацию в Firebase Console

1. Откройте [Firebase Console](https://console.firebase.google.com/)
2. Выберите ваш проект
3. Перейдите в **Authentication** в†’ **Sign-in method**
4. Нажмите на **Email/Password**
5. Включите переключатель **Enable**
6. Нажмите **Save**

### 2. Настройте правила Firestore для авторизованных пользователей

**ВАЖНО:** Без правильной настройки правил вы получите ошибку "Missing or insufficient permissions"!

В Firebase Console перейдите в **Firestore Database** в†’ **Rules** и установите:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Разрешить чтение всем
    match /{document=**} {
      allow read: if true;
    }
    
    // Разрешить запись только авторизованным пользователям
    match /movies/{movieId} {
      allow write: if request.auth != null;
    }
    
    // Правила для коллекции дорам
    match /doramas/{doramaId} {
      allow write: if request.auth != null;
    }
    
    // Правила для коллекции users
    match /users/{userId} {
      // Чтение: все могут читать
      allow read: if true;
      
      // Создание: только авторизованные пользователи могут создавать свой профиль
      allow create: if request.auth != null && request.auth.uid == userId;
      
      // Обновление: только владелец профиля может обновлять
      allow update: if request.auth != null && request.auth.uid == userId;
      
      // Удаление: только владелец профиля может удалять
      allow delete: if request.auth != null && request.auth.uid == userId;
    }
    
    // Правила для коллекции watchHistory (история просмотра)
    match /watchHistory/{historyId} {
      // Чтение: только владелец может читать свою историю
      allow read: if request.auth != null && request.auth.uid == resource.data.userId;
      
      // Создание: только авторизованные пользователи могут создавать записи в своей истории
      allow create: if request.auth != null && request.auth.uid == request.resource.data.userId;
      
      // Обновление: только владелец может обновлять свою историю
      allow update: if request.auth != null && request.auth.uid == resource.data.userId;
      
      // Удаление: только владелец может удалять из своей истории
      allow delete: if request.auth != null && request.auth.uid == resource.data.userId;
    }
  }
}
```

**После изменения правил нажмите "Publish" для сохранения!**

## Использование

### Регистрация нового пользователя

1. Откройте приложение
2. Перейдите на страницу регистрации (или нажмите "Регистрация" на странице входа)
3. Заполните форму:
   - Имя
   - Email
   - Пароль (минимум 6 символов)
   - Повторите пароль
   - Логин
4. Нажмите "Продолжить"
5. Выберите аватар профиля:
   - **Готовые аватары**: Кликните на один из 8 готовых аватаров
   - **Загрузка с устройства**: Кликните на последний кружок (с иконкой фото) - откроется проводник для выбора изображения с вашего устройства
   - Изображение должно быть формата JPG, PNG и размером не более 5MB
6. Нажмите "Завершить регистрацию"
7. После успешной регистрации вы будете перенаправлены на страницу профиля

### Вход в систему

1. Откройте приложение
2. Перейдите на страницу входа
3. Введите:
   - Email
   - Пароль
4. Нажмите "Вход"
5. После успешного входа вы будете перенаправлены на страницу профиля

### Добавление фильмов (только для авторизованных пользователей)

1. Войдите в систему
2. Перейдите на страницу добавления фильмов (через консоль: `window.location.hash = 'addmovies'`)
3. Нажмите "Добавить фильмы"
4. Дождитесь завершения операции

### Добавление дорам (только для авторизованных пользователей)

1. Войдите в систему
2. Откройте консоль браузера (F12)
3. Выполните команду: `await addDoramasToFirebase()`
4. Дождитесь завершения операции

**Примечание:** Убедитесь, что в правилах Firestore добавлены правила для коллекции `doramas` (см. раздел выше).

## Обработка ошибок

Система автоматически обрабатывает следующие ошибки:

- **Email Сѓже используется** - при попытке зарегистрироваться с существующим email
- **Неверный email или пароль** - при неправильных данных для входа
- **Слабый пароль** - пароль должен содержать минимум 6 символов
- **Пароли не совпадают** - при регистрации
- **Незаполненные поля** - все обязательные поля должны быть заполнены

## Структура данных пользователя в Firestore

При регистрации создается документ в коллекции `users` со следующей структурой:

```javascript
{
  uid: "user_id_from_firebase_auth",
  email: "user@example.com",
  name: "Имя пользователя",
  username: "логин",
  profileImage: "url_to_image" | null,
  createdAt: "2024-01-01T00:00:00.000Z",
  updatedAt: "2024-01-01T00:00:00.000Z"
}
```

## API сервиса аутентификации

### `registerUser(email, password, userData)`
Регистрирует нового пользователя.

**Параметры:**
- `email` (string) - Email пользователя
- `password` (string) - Пароль (минимум 6 символов)
- `userData` (object) - Дополнительные данные:
  - `name` (string) - Имя пользователя
  - `username` (string) - Логин
  - `profileImage` (string | null) - URL изображения профиля

**Возвращает:**
```javascript
{
  success: true,
  user: { ... } // Данные пользователя
}
// или
{
  success: false,
  error: "Сообщение об ошибке"
}
```

### `loginUser(email, password)`
Вход пользователя в систему.

**Параметры:**
- `email` (string) - Email пользователя
- `password` (string) - Пароль

**Возвращает:** аналогично `registerUser`

### `logoutUser()`
Выход пользователя из системы.

### `getCurrentUser()`
Получает текущего авторизованного пользователя.

**Возвращает:** объект пользователя или `null`

### `onAuthStateChange(callback)`
Подписывается на изменения состояния аутентификации.

**Параметры:**
- `callback` (function) - Функция, вызываемая при изменении состояния

**Возвращает:** функция для отписки
